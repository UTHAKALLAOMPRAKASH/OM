# Fixed execution sections

0. Foundation: docs, wiring, firmware/mock, isolated pinned environment.
1. Shell and packaging: panel, overlay, local model, early package size.
2. Posture: acquisition, regional quality, calibration, fast decisions and tests.
3. Hardware: firmware protocol, serial, freshness, modes and fault tests.
4. Integration: overlay, controls, notification routing, stop/recovery.
5. Productivity: reminders, timers, use estimate; optional blink/soft limits.
6. Reports: SQLite, coverage, durations, scores, 60-day cleanup.
7. Release: integrated tests, offline/privacy checks, installer, size, user guide.

Time budgets: 0–8h sections 0/1; 8–24h section 2; 24–36h sections 3/4;
36–48h section 5; 48–58h section 6; 58–72h section 7. Independent work may overlap.
Do not claim hardware, visual or accuracy validation from numerical tests alone.
